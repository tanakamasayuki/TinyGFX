# 組込み検証プラットフォーム — 文書の入口

内部の記録。日本語のみ。**2026-09-03 全面改訂**（議論と E22 の結果を反映）。

**先にあるべき姿を決め、既存のものはそれに合わせて作り直す。** 既存には
各テストの自前モデル・TinyM5Board のトレース・I2CDeviceDB の現在の形も含む。
どれも素材であって錨ではない。

方針は 2 つ。

- **いまの工数より今後の工数のほうが大きい。** 足すたびに壊れないことを優先する
- **契約はフレームワークにも実行形態にも依存させない。** Arduino は
  「最初から同梱されている 1 ポート」であって前提ではない
